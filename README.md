Project : Diagnostic Santé
 Description

Ce projet est une application de diagnostic santé qui permet aux utilisateurs d’analyser leurs symptômes et de recevoir des recommandations médicales simples.

 *Objectifs
Aider les utilisateurs à comprendre leurs symptômes
Fournir des conseils rapides
Faciliter l’accès à l’information médicale
 *Méthodologie
Design Thinking
Méthode Agile (Scrum simplifié)
 *Outils utilisés
GitHub (gestion du projet)
Trello (organisation des tâches)
* Utilisateurs ciblés
Adultes
Utilisateurs ayant des symptômes de santé
**Statut

Projet en cours de développement
